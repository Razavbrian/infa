# INFA Frontend - Institut National de Formation Administrative

Site web officiel de l'INFA Madagascar développé avec Next.js 14, TypeScript et Tailwind CSS.

## 🚀 Démarrage Rapide

### Prérequis
- Node.js 18.17+ ou 20+
- npm 9+ ou yarn 1.22+
- Strapi backend tournant sur http://localhost:1337

### Installation

```bash
# Installer les dépendances
npm install

# Copier le fichier d'environnement
cp .env.local.example .env.local

# Modifier .env.local avec vos configurations

# Démarrer le serveur de développement
npm run dev
